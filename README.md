# Portfolio
This is my personal portfolio 

The marketing portfolio of Neeshma Mehta, a product marketer based in Raleigh, NC.

## What's here
- `index.html`: the whole site, one page with no build step
- `neeshma-mehta.jpg`: portrait photo
- `Neeshma_Mehta_Resume.pdf`: the resume the site's download buttons link to
- `.nojekyll`: tells GitHub Pages to serve the files as they are

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
3. After a minute or two the site is live at https://neeshma-04.github.io/Portfolio/

To use your own domain, such as neeshmamehta.com, enter it under **Settings → Pages → Custom domain**, then add the DNS records from GitHub's custom domain guide wherever you bought the domain.
